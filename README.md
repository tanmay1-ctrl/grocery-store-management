# Grocery Store Management System

A desktop-based grocery store management application developed using Python, Tkinter, and SQLite.

## Features
- Add, update, delete, and search products
- Manage inventory and monitor low-stock products
- Generate bills and receipts
- Automatically update stock after checkout
- View sales history and dashboard totals
- Store product and sales information using SQLite

## Technologies Used
- Python 3.9+
- Tkinter
- SQLite

## Installation and Usage

1. Install Python 3.9 or later.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the application:

   ```bash
   python grocery_store.py
   ```

   On Windows, you can also use `py grocery_store.py`.

## Database

The application creates a local SQLite database automatically when needed. Back up your database if you want to preserve your store's records.

## Project Purpose

This project demonstrates Python programming, GUI development, database management, inventory tracking, and billing operations.

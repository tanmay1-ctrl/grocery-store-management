GROCERY STORE MANAGEMENT SYSTEM

Requirements:
- Python 3.9 or later with Tkinter installed.
- No pip packages required.

Run:
1. Open a terminal in this folder.
2. Run: python grocery_store.py
   (On some Windows installations: py grocery_store.py)

Features:
- Add, update, delete, and search products.
- Manage stock and highlight low stock (5 or fewer).
- Add products to cart and checkout.
- Automatically reduce stock and save bills.
- View receipts, sales history, and dashboard totals.

Data is stored in grocery_store.db, automatically created next to the script.
Back up this database file to preserve your records.
